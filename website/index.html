    How the scores are calculated

    EgoPath Score gives equal weight to five tasks. For each traversability task, the contribution is twice balanced accuracy (BA) minus one. For each path task, it is the success rate (SR). The mean is scaled to 100. All task metrics are percentages.

    F1 measures precision and recall on feasible waypoints. Valid path rate (VPR) checks every edge. SR also requires arrival at an acceptable endpoint. SPL weights successful routes by their length relative to the shortest legal path.

    Research findings

    Where routes break down

    41.7% to 10.0%

    Adding a robot footprint

    GPT-6 Astra leads the zero-shot ranking. Its success rate falls from 41.7% on Point Path to 10.0% on the paired Embodied Path questions.

    54.2 vs. 48.7

    Human reference vs. Astra

    On a matched 50-question subset, the human reference leads Astra on EgoPath Score. Both succeed on 30% of the Embodied Path questions.

    0 to 10/50

    Success in closed-loop simulation

    EgoPath-SFT improves Qwen3.5-4B from zero to ten successful episodes on the same 50 tasks across 25 held-out Isaac Sim scenes.

    Following a legal first step

    Across ten models, 91.1% of Embodied Path predictions start with a legal edge. Only 8.4% stay legal throughout, and 1.9% reach an acceptable endpoint along a legal route.

    In a separate RGB-only study, four participants judged 40 short embodied paths and correctly classified 140 of 160 judgments (87.5%).

    On 50 matched route questions, Astra correctly labels 308 of 318 legal edges but only 21 of 59 illegal edges when asked about them individually.

    Each rate uses all predictions for that task across the ten zero-shot models.

    Benchmark tasks

    Inside a waypoint decision

    Explore real prompts and observations. Each question pairs a first-person view with visible waypoint IDs. Registered 3D geometry supplies the evaluator’s ground truth.

    ACTUAL BENCHMARK OBSERVATION
    POINT AGENT146 benchmark questions

    Where can a point agent go?

    Select every visible candidate that is traversable when the agent has no body width. This tests waypoint-to-scene correspondence and candidate feasibility.

    MODEL PROMPT

    The image shows numbered candidate points. Output a JSON array of display IDs that are walkable.

    Expected output
    An unordered set of traversable waypoint IDs.
    What is evaluated
    Candidate feasibility: balanced accuracy and F1.

    The two traversability examples share a scene and view. The Point Path and Embodied Path examples also share a scene, view, and target.

    01 — OBSERVE

    Image + goal

    First-person RGB and visible numbered waypoints are supplied to the model.

    →
    02 — DECIDE

    Waypoint IDs

    The prediction is a candidate set or an ordered route, expressed as a JSON array.

    →
    03 — VERIFY

    Scene-grounded outcome

    The evaluator checks agent-specific feasibility, every selected edge, and the endpoint.

    A reference route certifies that a solution exists.

    It is not the only answer a model may give. Any predicted route is evaluated against the same geometry and acceptable goal regions; path efficiency is measured after success. Scene geometry and ground-truth sidecars belong to the evaluator, not the model input.

    How the dataset is constructed +

    Scenes and views → visible waypoints and targets → point/embodied feasibility graphs → verified reference routes → questions and spatial CoT. Splits are formed by source group to keep related scans or regions together. The release contains 31,852 training, 1,345 validation, and 1,111 benchmark questions.
